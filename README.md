# hugolify-theme-realestates-sellers

## Install

Edit `config/_default/module.yaml` to install the `hugolify-theme-realestates-sellers` module:

### V2

```yml
imports:
  - path: github.com/hugolify/hugolify-theme-realestates-sellers/v2
  - path: github.com/hugolify/hugolify-theme-realestates/v2
  - path: github.com/hugolify/hugolify-theme/v2
```

### V1

```yml
imports:
  - path: github.com/hugolify/hugolify-theme-realestates-sellers
  - path: github.com/hugolify/hugolify-theme-realestates
  - path: github.com/hugolify/hugolify-theme
```
